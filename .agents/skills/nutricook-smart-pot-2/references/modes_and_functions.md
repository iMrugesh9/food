# Nutricook Smart Pot 2: Modes & Functions Deep Dive

The Nutricook Smart Pot 2 integrates 9-to-12 distinct appliance functions. This manual details how each mode operates, lid status requirements, temperature levels, and typical recipes.

---

## 1. Summary of Functions & Lid Requirements

| Function | Pressure Active? | Lid Status | Temperature / Range | Common Uses |
| :--- | :--- | :--- | :--- | :--- |
| **Pressure Cook** | Yes (High/Low) | Locked (Auto-sealing) | 110°C – 118°C | Curries, pulses, stews, tough meats |
| **Sauté** | No | Off (Lid Open) | Less: ~135°C / Normal: ~160°C / More: ~175°C | Browning, whole spices, simmering, reducing |
| **Slow Cook** | No | Closed (or glass lid) | Less: ~85°C / Normal: ~90°C / More: ~95°C | All-day braises, pot roasts, chilis |
| **Rice** | Yes (Low/High) | Locked | Standard rice cycle | White rice, basmati, jasmine |
| **Soup / Broth** | Yes (High) | Locked | High Pressure | Chicken noodle, clear broth, bone broth |
| **Steam** | No or Low | Locked with steam rack | 100°C steam | Veggies, momos, idlis, fish fillets |
| **Yogurt** | No | Closed loosely | Boil: 83°C / Incubate: 40°C–43°C | Curd, greek yogurt, fermented batter |
| **Sous Vide** | No | Closed | 25°C – 90°C (exact 1°C steps) | Salmon, steak, chicken breast, eggs |
| **Keep Warm** | No | Closed | 63°C – 78°C | Holds food safely up to 10–24 hours |
| **Delay Start** | Timer | Dependent on program | Delay up to 24 hours | Scheduling morning oats or evening rice |

## 2. Advanced Mode Instructions

### Sauté Mode: 3 Heat Tiers
* **Less:** Use for sweating onions without browning, melting butter/ghee, or gently thickening sauces with cornstarch.
* **Normal:** The workhorse setting. Perfect for tempering mustard seeds, cumin, ginger-garlic paste, and everyday sautéing.
* **More:** High searing heat. Use for deep browning of chicken cubes, lamb chunks, or searing steaks before pressure braising.
* **Timer:** Configurable from 1 to 60 minutes. Shuts off automatically if left unattended for 30–60 minutes.

### Sous Vide Mode: Temperature Precision
* Use water volume filled to halfway.
* Set temperature according to target meat doneness:
  * Rare Beef/Lamb: 52°C – 54°C
  * Medium-Rare Beef: 55°C – 57°C
  * Silky Salmon: 46°C – 50°C
  * Juicy Chicken Breast: 63°C – 65°C
* Once water reaches target temperature (unit beeps "Hot"), submerge the vacuum-sealed pouch.

### Delay Start (Smart Scheduling)
* Select the desired cooking program and set cook time.
* Press **Delay Start** and use `+` / `-` to set the delay interval (e.g. `04:00` for 4 hours).
* Cooking will begin exactly when the countdown completes.
* **Food Safety Alert:** Never use Delay Start with raw fish, pork, poultry, or dairy at ambient room temperatures above 20°C for more than 1–2 hours.
